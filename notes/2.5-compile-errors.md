# 2.5 compile errors (first run)

First offline compile check on patch 2.5, 2026-10-25: `pwsh tools/compile-check.ps1`, which compiles `src/` plus the 12 framework scripts (Codeware 1.x, TweakXL, ArchiveXL, Mod Settings 0.2.22) against the vanilla 2.5 bundle (build 26161058), using redscript-cli 0.5.32.

Is the list complete? A probe file with three kinds of error (unresolved method, type mismatch, temporary passed by reference) got all three reported in one run, so one error kind doesn't hide the others. It is very likely the whole list.
