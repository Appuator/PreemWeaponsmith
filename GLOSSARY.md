# Preem Weaponsmith

A Cyberpunk 2077 mod that adds a weapon-mod crafting system: players choose mods at the crafting bench that change how the crafted weapon behaves.

## Language

**Preem mod**:
A mod from this mod's catalogue that the player chooses when crafting, such as Tech Barrel, InstaBurst Trigger or Shock Blade. Distinct from the game's own weapon mods and attachments.
_Avoid_: attachment, upgrade

**Mod style**:
The specific kind of a Preem mod (for example `Barrel_Tech`, `Mag_Thermal`); each Preem mod has exactly one.
_Avoid_: mod type

**Slot class**:
The category a Preem mod belongs to and the slots it fits: Barrel, Trigger, Magazine (ranged) or Blade, Handle (melee).
_Avoid_: mod class (in code it is `PreemModClassType`)

**Preem slot**:
One of the two positions per slot class on a weapon where a Preem mod can be installed.

**Brake twin**: `Items.PreemSilenced_<brake>`, a player muzzle brake's record plus the `Silenced` tag. It takes the brake's place in the muzzle slot while the Integral Silencer is on, so the gun keeps the brake and plays its suppressed shot (ADR 0002 addendum). Never left in the inventory.

**Hidden muzzle part**:
The statless part (`Items.PreemSilencerMuzzle`) the mod puts in a weapon's muzzle slot while the Silencer is installed, so the game plays the weapon's silenced sound (ADR 0002). Never offered or shown as a Preem mod.
_Avoid_: helper mod, fake silencer

**Evolution**:
The game's weapon family: Power, Tech or Smart. Some barrel mods change it.

**Evolution variant**:
A copy of a vanilla weapon with a different evolution, generated by the mod so that an evolution barrel can turn, say, a Power rifle into a Tech one.

**Unlock mode**:
The setting deciding which Preem mods are available: Sandbox (all) or Weapon Blueprints (by the crafted weapon's rarity).
_Avoid_: progression mode

**Mod limit**:
The maximum number of Preem mods one weapon can carry, set by the limit mode setting.

**Self-check**:
The dev-only routine that confirms every Preem record the mod relies on exists and resolves on the current game patch.

**Sound set**:
The game's per-weapon sound settings (e.g. `wea_pla_liberty`, with a `_suppressor` twin) that name which existing sound plays for a single shot, the auto-fire loop and its stop, bursts and charging. The mod fills empty entries with sounds borrowed from other weapons.
_Avoid_: sound event (that is one sound), audio archive

**mod.io build**:
The console / cross-platform version of the mod. It is generated from the PC source by the converter and never edited by hand (ADR 0003).
_Avoid_: console fork, REDmod port

**Convertible subset**:
The redscript forms the PC source is limited to so the converter can turn them into the official compiler's syntax mechanically, such as written `let` types and no escapes inside strings. Enforced by lint.

**Add-on**:
A separate mod that adds its own Preem mods to the catalogue by extending `PreemAddon`; core finds it and treats its mods like its own (SPEC §9, `docs/ADDONS.md`). The first is the hacker barrels add-on.
_Avoid_: plugin, expansion, extension

**Add-on mod ID**:
The name an add-on gives one of its mods (a CName prefixed with the add-on's module, such as `PreemHackerBarrels.Breach`). Core gives each ID a mod style for the game session; the ID, not the style, is what stays the same.
_Avoid_: add-on style (the style is the runtime value, not the name)
